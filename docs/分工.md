# easySVA 小组分工

**一句话：同学 A 守住唯一的 Ubuntu 演示机并主攻国标流媒体，同学 B 主攻睡岗算法并和 A 一起在虚拟机上把 C++ 集成做完，同学 C（Mac）主攻前后端业务、仓库和文档统稿，每人每个验收点都有能拿出来的产出。**

协作 AI 开工前必须先读：

1. [当前阶段.md](./当前阶段.md)（阶段禁令只在这一份）
2. 本文
3. 当前用户对应的角色手册（下面三份之一）
4. [PR规范.md](./PR规范.md)

| 角色 | 机器 | 手册 |
| --- | --- | --- |
| 同学 A | Windows 宿主机 + Ubuntu 22.04 x86_64 虚拟机 | [roles/A-流媒体与演示机.md](./roles/A-流媒体与演示机.md) |
| 同学 B | Windows（不装 Linux） | [roles/B-算法与分析器.md](./roles/B-算法与分析器.md) |
| 同学 C | Apple 芯片 Mac（只写代码，不部署） | [roles/C-前后端与合稿.md](./roles/C-前后端与合稿.md) |

仓库是一个 GitHub monorepo：`backend/`、`web/`、`server/`、`mediaServer/`、`docs/`。上游源码在 Gitee 四个仓，日常开发只走 GitHub。能写哪些功能以 [当前阶段.md](./当前阶段.md) 为准。
