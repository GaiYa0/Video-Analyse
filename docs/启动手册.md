# 演示机启动手册（同学 A）

> 路径以本机为准：仓库 `E:\video-analysis\Video-Analyse-main`；运行产物在 WSL `/opt/SVA/`。  
> 更完整的环境说明见 [deploy-notes.md](./deploy-notes.md)。

## 0. 先搞清：谁负责什么

| 组件 | 干什么 | 默认端口 | 进程特征 |
| --- | --- | --- | --- |
| MariaDB | 业务库 `easySVA` | **3307** | `mysqld` |
| Redis | 缓存 | **6379** | `redis-server` |
| Nginx | 前端静态页 + 反代 API | **80** | `nginx` |
| backend.jar | 设备/布控/告警/调 ZLM | **9114** | `java -jar backend.jar` |
| MediaServer (ZLM) | 拉流转协议、预览 | HTTP **9992** / RTSP **9994** / RTMP **9995** | `MediaServer` |
| Analyzer | YOLO / 睡岗推理 | （被 backend 调） | `Analyzer -f` |
| WVP（P3 国标可选） | SIP **5060** 注册信令 | Web **18080** / SIP **5060** | `wvp-pro-*.jar` |

日常 **P1/P2** 只需前 6 项；做 **P3 国标注册** 再加 WVP。

## 1. 日常一键启动（推荐）

在 **Windows PowerShell**：

```powershell
cd E:\video-analysis\Video-Analyse-main
.\scripts\start_easysva.ps1
```

| 这条命令实际启动 | 说明 |
| --- | --- |

打开网页：见下面 **§1.1**（Clash 时用 `http://localhost:8080/`）。

## 1.1 网页地址（本机 A / 同学 B·C）

业务页给三人用；WVP 是国标 SIP 管理页，一般只有演示机本机要开。

### 演示机本机（同学 A）

Clash / VPN 开着时只用回环地址，**不要**用局域网 IP 的 `:80`（容易 502）。

| 页面 | 地址 | 账号 |
| --- | --- | --- |
| **easySVA 业务前端**（设备 / 布控 / 告警） | http://localhost:8080/ | `admin` / `admin123` |
| 同上（不带端口，不稳时改 8080） | http://localhost/ | 同上 |
| **WVP 国标管理页**（注册、通道、点播） | http://127.0.0.1:18080/ | `admin` / `SvaDemo@2026` |

国标水杯：业务页找 **demo-ipc** →「同步国标设备」→ 预览 / 布控。点播出画也可在 WVP：**设备接入 → 国标设备 → 通道 → 播放**。

### 同学 B、C（另一台电脑）

先关 Clash/VPN，浏览器打开：

```text
http://<A 的局域网 IP>:8080/
```

现网示例（DHCP 会变，以 A 当场 `ipconfig` 的 WLAN IPv4 为准）：

```text
http://10.21.184.30:8080/
```

- **必须带 `:8080`**，不要写成 `http://10.x.x.x/`（80 端口）。
- 账号同样是 `admin` / `admin123`。
- 连不上时：同一 WiFi；A 已关 Clash；A 用管理员 PowerShell 跑 `.\scripts\setup_windows_lan_access.ps1`。

日常点这些就够：

1. 登录
2. 设备管理：直连设备 + 国标 **demo-ipc**

发给 B/C 可直接复制：

> 关 Clash，打开 `http://<A当前IP>:8080/`，账号 `admin` / `admin123`。看监控用监控墙，不要依赖设备列表弹窗预览。

### 2.5 P3：国标 SIP（WVP）

**首次**（只需做一次）：

```bash
cd /mnt/e/video-analysis/Video-Analyse-main
bash scripts/setup_wvp.sh      # 建库 wvp、写 easysva 配置
bash scripts/build_wvp.sh      # JDK 21 编译 jar
# 前端静态页（管理页空白时）：
bash scripts/serve_wvp_ui.sh   # 编译 web 并挂到 /opt/SVA/wvp/static 后重启
```

**日常启动 WVP**：

```bash
bash scripts/start_wvp.sh
```

| 指令 | 启动内容 |
| --- | --- |
| `setup_wvp.sh` | MariaDB 库 `wvp` + 配置，不长期占端口 |
| `build_wvp.sh` | 编译 `/opt/wvp-GB28181-pro/target/wvp-pro-*.jar` |
| `start_wvp.sh` | WVP：Web **18080**、SIP **5060**；并把 ZLM hook 指到 WVP |
| `serve_wvp_ui.sh` | 补管理前端静态资源并重启 WVP |

管理页：`http://127.0.0.1:18080/`  
演示机账号：`admin` / `SvaDemo@2026`  
SIP 只绑局域网 IP（如 `10.21.235.102:5060`），模拟器必须往这个 IP 注册，不要用 `127.0.0.1:5060`。  
业务网页同步国标：设备管理 → **同步国标设备**。

无真机时走 **真 SIP 注册 + 点播出画面**（不要用 `seed_wvp_device.sh` 冒充在线）：

```powershell
wsl -d Ubuntu-22.04 -u root -- bash /mnt/e/video-analysis/Video-Analyse-main/scripts/start_gb_sim.sh
```

| 指令 | 启动内容 |
| --- | --- |
| `start_gb_sim.sh` | 模拟 IPC：REGISTER/保活/目录 → 自动点播 → ZLM `app=rtp` 出 cup 测试画面 |

脚本会保持 `gb28181_sim.py` 运行；预览地址以脚本打印的 `rtp/<device>_<channel>.live.flv` 为准。`seed_wvp_device.sh` 只改数据库，**不会** REGISTER，点播无画面。本机模拟器会把 WVP 设备 `sdp_ip` 写成 `127.0.0.1`（避免局域网 DHCP 换 IP 后 INVITE 发到旧地址）；真机仍用当前局域网 IP。

### 2.6 怎么看 WVP 点播（出画面）

先保证：easySVA 已起、WVP 已起、**刚跑过或正在跑** `start_gb_sim.sh`（模拟器进程不能关）。Clash/VPN 开着时只用 **127.0.0.1**，不要用局域网 IP。

**方法 A：WVP 管理页（推荐）**

1. 浏览器打开 [http://127.0.0.1:18080/](http://127.0.0.1:18080/)  
2. 登录：`admin` / `SvaDemo@2026`  
3. 左侧 **设备接入 → 国标设备**  
4. 找到 `34020000001320000001`，状态应为 **在线**  
5. 点该行 **通道**  
6. 通道 `demo-ipc` 上点 **播放**，弹出「视频播放」窗口，应看到 cup 测试画面（手持杯子）

`start_gb_sim.sh` 结束时已经自动点播过一次；你再点「播放」是再拉一次流，可以。

**方法 B：浏览器 / 播放器直接打开 FLV**

脚本成功时打印的地址（stream 是 **设备ID_通道ID**）：

```
http://127.0.0.1:9992/rtp/34020000001320000001_34020000001320000001.live.flv
```

- VLC：媒体 → 打开网络串流 → 粘贴上面的 http 地址  
- Chrome 往往 **不能** 直接播 HTTP-FLV，请用方法 A 或 VLC  

**方法 C：业务网页**（看的是同步进 easySVA 的国标设备，不是 WVP 自己的播放器）

1. [http://localhost:8080/](http://localhost:8080/) 登录 `admin` / `admin123`  
2. 设备管理里认名字 **demo-ipc**（国标编码 `34020000001320000001`），点 **预览视频**  
3. 不要对半程测试/SSRC 残留行点同步；「同步国标设备」现在只会收 WVP 已注册通道，不再把 `gbcam001`、8 位十六进制 SSRC 建成新设备

### 2.7 接入真正的国标 IPC（替换水杯）

水杯画面来自 `start_gb_sim.sh`，不是摄像头。真机与模拟器不要同时用同一个国标编码。

1. **停模拟器**（编码不同可并存，建议先停以免搅在一起）：  
   `wsl -d Ubuntu-22.04 -u root -- bash -lc "pkill -f gb28181_sim.py || true"`
2. 演示机已起：`start_easysva.ps1` + `start_wvp.sh`。Clash 可关，或至少别让它拦局域网。
3. Windows 防火墙放行 **UDP/TCP 5060**，以及 **UDP 30000–35000**（RTP 媒体）。
4. 摄像头与演示机同一局域网，能 ping 通演示机当前 IP（DHCP 会变；现网示例 `10.21.184.30`。变了要改 WVP `sip.ip` 和摄像机里的 SIP 服务器地址）。
5. 在摄像机「国标 / GB28181」里填：

| 摄像机项 | 填这个 |
| --- | --- |
| SIP 服务器地址 | 演示机当前局域网 IP（**不要** `127.0.0.1`） |
| SIP 端口 | `5060`（UDP，部分机型可 TCP） |
| SIP 服务器 ID / 平台 ID | `34020000002000000001` |
| SIP 域 | `3402000000` |
| 设备国标编码 | 机身 20 位编码（**不要**再用模拟器的 `34020000001320000001`） |
| 注册密码 | `12345678` |
| 心跳 | 建议 ≤ 60 秒 |

6. 保存后等几十秒。WVP [http://127.0.0.1:18080/](http://127.0.0.1:18080/) → **设备接入 → 国标设备**：新编码 **在线** → **通道 → 播放**，应是现场画面。
7. 若注册成功但点播黑屏：WVP 里把该设备传输模式改成 **UDP**（不要 TCP-PASSIVE），再点播放。
8. 业务页「同步国标设备」，出现该通道后可预览。睡岗/YOLO 布控：国标 Analyzer 拉 `rtsp://…/rtp/<设备_通道>`；直连 RTSP 仍拉 `live/<ape_id>`。ZLM 还没有该 rtp 流时，backend/Analyzer 拉流会触发 WVP `on_stream_not_found` 自动 INVITE，不必先手动点播。停模拟器（SIGTERM）后 WVP 应马上离线，再点同步，业务列表 `is_online=0`。

## 7. 常见坑

| 现象 | 处理 |
| --- | --- |
| 网页 502 | 后端没起：重跑 `start_easysva.ps1` |
| 同步出国标一堆「登录中」 | 旧逻辑把 ZLM 半程口、SSRC hex 也建成设备；已过滤。只认 **demo-ipc**。刷新列表即可 |
| `18080` 打开空白/404 | 跑过 `serve_wvp_ui.sh`；强制刷新 |
| 同学打不开网页 | 见 **§1.1**：关 Clash/VPN；用 `http://<本机IP>:8080/`（不要 `:80`）；管理员跑 `setup_windows_lan_access.ps1` |
| WVP 点播黑屏 / 超时 | 模拟器是否还在跑；设备是否在线；stream 是 `设备ID_通道ID`；Clash 时用 `127.0.0.1` 不要用局域网 IP |
| Chrome 打开 `.live.flv` 没画面 | 正常，用 WVP 页「播放」或 VLC |
